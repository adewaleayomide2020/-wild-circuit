# WILD CIRCUIT

A browser-based 3D arcade racing prototype built with Three.js and Vite.

## Run locally

1. Install Node.js.
2. Run \`npm install\`.
3. Run \`npm run dev\`.
4. Open the local URL shown by Vite.

## Controls

- **W / Up Arrow:** Accelerate
- **S / Down Arrow:** Brake
- **A / Left Arrow:** Steer left
- **D / Right Arrow:** Steer right
- **E:** Phase Pulse (temporarily slows nearby AI rivals)
- **Space:** Ion Shield (temporary defensive shield)

Touch controls are available on smaller screens.

## Current prototype

- 3D oval circuit with a chase camera
- Three computer-controlled rivals
- Three-lap race and finish screen
- Phase Pulse and Ion Shield abilities
- Desktop keyboard and mobile touch controls

Online multiplayer, sound effects, track selection, and vehicle customization are planned for later iterations.
